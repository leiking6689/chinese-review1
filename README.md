# 六年级上册语文总复习与练习网站（扩展版）

单文件静态网站，无任何外部依赖，可直接用浏览器打开，也可部署到 GitHub Pages。

## 内容范围
- 现代文 7 课：草原 · 丁香结 · 古诗词三首 · 七律·长征 · 狼牙山五壮士 · 开国大典 · 我的战友邱少云
- 文言文 2 篇：伯牙鼓琴 · 陈太丘与友期行
- 整本书阅读：高尔基《童年》
- 四大板块：知识速览 ｜ 字词大盘点 ｜ 分课练习（30 题）｜ 综合测试卷（100 分，含课外记叙文阅读与习作）

## 本地打开
双击 `index.html` 即可（电脑、手机浏览器均可）。

## 部署到 GitHub Pages
1. 在 GitHub 新建一个仓库（如 `grade6-chinese`）。
2. 把本包内的 `index.html` 上传到仓库根目录。
3. 进入仓库 **Settings → Pages**。
4. Source 选择 **Deploy from a branch**；Branch 选择 `main`、目录选 `/ (root)`，保存。
5. 等待约 1 分钟，页面会显示访问地址：
   `https://你的用户名.github.io/仓库名/`

## 打印
在浏览器中按 Ctrl/Cmd + P，页面已按 A4 排版优化；自测题与试卷答案打印时会自动显示。
